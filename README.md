# 半導体業界ダイジェスト（スマホ向け1）

- `index.html`: 見出しをタップして詳細・出典を開くレスポンシブWebページ
- `report.md`: 表示する記事本文。ページはこのファイルを読み込み、再読み込みまたは約1分ごとに内容を更新します
- `manifest.json`: ホーム画面への追加に使うWebアプリ設定
- `sw.js`: ページの基本ファイルをキャッシュし、記事Markdownはネットワークから再取得
- 読了チェック: 現在は各端末のブラウザー内に保存。チームで確認状況を共有する機能は未接続

## 最新版

- レポート期間: 2026年11月19日〜20日
- 主な話題: NVIDIA決算、TSMCの中国系設計会社向け先端製造制限報道、Intel 18A-Pの外部顧客獲得
- 国内重点: SCREEN、川崎重工の期間内新着を確認。該当する新規発表は見つからず

この試作を社内でスマホ利用するには、社内Web領域への配置が必要です。Markdownの変更をアプリに反映するには、Web領域にある`report.md`を差し替えます。全員共通の読了状況を集計するには、社内認証と共有データ保存先を追加します。
